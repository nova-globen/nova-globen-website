Fravashi

A self-hosted studio where AI coding agents work on your software inside one desktop window, connected to the repository, tracker and wiki you already use, with a person approving what they change.

Why it exists

Teams that adopt AI coding agents easily lose control and context: work items, documentation and code live in three separate tools, and agents change code with nobody reviewing each step. Fravashi keeps the work and the knowledge together as one linked whole, so an agent takes its context from there, and a person directs and approves the work along the way.

It is for software teams and companies who want AI agents, but on their own machines and under their own review.

What it does

  • An agent session in the studio

    An AI coding agent works on an isolated copy of the repository; its changes ask for a person's approval first, and commands and anything outside the copy always do.

  • A second review

    Every commit an agent makes is reviewed by a second agent before a person is asked to approve it.

  • Tracker and wiki

    A built-in tracker and wiki that connect to Azure DevOps Boards and Jira for work, and Confluence for documentation; changes go out when you send them, never silently.

  • Code and pull requests

    Git and pull requests on GitHub, Azure DevOps and Forgejo, with a code editor in the studio.

  • Autopilot

    Marked work items are built unattended, each in its own working copy, and the result is judged against the item.

Availability

Fravashi is in development and not yet generally available. It runs as a Windows desktop application that hosts the studio in a Linux container on your own machine.
