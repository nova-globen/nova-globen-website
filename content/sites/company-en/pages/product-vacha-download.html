Or install it with a command

The Store version, with winget:

winget install --id 9NSCM5WH4WF1 --source msstore

winget asks you to accept the Store's terms the first time. If you already installed Vacha with the installer below, winget can report it as installed and change nothing. If it does, use the Store link instead.

The installer from GitHub, in PowerShell. It starts only if the download matches its published checksum. It downloads 94 MB and shows nothing until it has finished:

$ProgressPreference = 'SilentlyContinue'
$base = "https://github.com/nova-globen/vacha/releases/latest/download"
$setup = "$env:TEMP\vacha-setup-x64.exe"
$sums = "$env:TEMP\vacha-SHA256SUMS"
Invoke-WebRequest "$base/vacha-setup-x64.exe" -OutFile $setup
Invoke-WebRequest "$base/SHA256SUMS" -OutFile $sums
$expected = ((Select-String 'vacha-setup-x64.exe' $sums).Line -split '\s+')[0]
if ((Get-FileHash $setup).Hash -eq $expected) { Start-Process $setup } else { Write-Error "The checksum does not match. Do not run this file." }

The installer upgrades a Vacha or Tond you installed yourself before, and keeps its settings. It is not code-signed, so the command above relies on the checksum check. If you download the file in a browser instead, Windows may warn you before it runs. The Store version is signed.
