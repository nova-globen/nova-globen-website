Nova Globen Vacha

A text and code editor for Windows: it opens a file the way Notepad does and edits it the way a code editor does.

Why it exists

People who open text, configuration, log and code files all day want something that appears as quickly as Notepad but edits properly, without the weight of a full development environment. Vacha has the editing (tabs, syntax highlighting, find and replace, multiple cursors) and leaves out the rest: no terminal, no git, no extensions and no workspaces.

Once Vacha is running, it opens a file in about 0.14 seconds (the median of five runs on a Ryzen 9 9950X3D with Windows 11, x64).

Vacha (VA-cha) is Avestan for "word". It was called Tond up to version 1.0.0.
