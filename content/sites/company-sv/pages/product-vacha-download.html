Hämta Vacha i Microsoft Store

Versionen från Store är signerad och uppdateras av Store. Den uppgraderar inte en Vacha eller Tond som du installerat själv: den installeras bredvid och håller sedan sina inställningar för sig.

Eller installera den med ett kommando

Versionen från Store, med winget:

winget install --id 9NSCM5WH4WF1 --source msstore

Första gången ber winget dig godkänna Store-villkoren. Om du redan har installerat Vacha med installationsprogrammet nedan kan winget ange att den är installerad och inte ändra något. Använd i så fall länken till Store.

Installationsprogrammet från GitHub, i PowerShell. Det startar bara om nedladdningen stämmer med den publicerade kontrollsumman. Det laddar ned 94 MB och visar ingenting förrän det är klart:

$ProgressPreference = 'SilentlyContinue'
$base = "https://github.com/nova-globen/vacha/releases/latest/download"
$setup = "$env:TEMP\vacha-setup-x64.exe"
$sums = "$env:TEMP\vacha-SHA256SUMS"
Invoke-WebRequest "$base/vacha-setup-x64.exe" -OutFile $setup
Invoke-WebRequest "$base/SHA256SUMS" -OutFile $sums
$expected = ((Select-String 'vacha-setup-x64.exe' $sums).Line -split '\s+')[0]
if ((Get-FileHash $setup).Hash -eq $expected) { Start-Process $setup } else { Write-Error "Kontrollsumman stämmer inte. Kör inte den här filen." }

Installationsprogrammet uppgraderar en Vacha eller Tond som du installerat själv tidigare, och behåller dess inställningar. Det är inte kodsignerat, så kommandot ovan förlitar sig på kontrollsumman. Om du i stället laddar ned filen i en webbläsare kan Windows varna innan den startar. Versionen från Store är signerad.

  • Installationsprogrammet som fil (94 MB)
  • Zip-filen (134 MB) körs utan installation. Den sparar sina inställningar i din användarprofil och startar med Windows om du inte stänger av det.
  • SHA256SUMS, SHA-256-kontrollsumman för varje fil
  • Programvaruförteckning (SBOM) (CycloneDX)
